# Library v2

Library v2 is deployed at https://stash.kasitek.co.za with the shared API/MCP at https://api.stash.kasitek.co.za. Hosted capture, PDF processing, summaries, agent retrieval, full backup restore and account isolation passed. Physical cleanup passed after the ten-minute delay, with zero remaining Backblaze versions. Track the release in [the checklist](../../LIBRARY_V2_IMPLEMENTATION.md) and [rollout record](../library-v2-rollout.md).

Cards open private `/items/[id]` reading pages. Open source and menus remain separate; text can be selected. Direct links require the owning account. Library filters and return navigation persist. Links, URL-free notes/ideas and private PDFs support search, multiple collections, favourites, archive and 30-day Trash. Undo is available after reversible lifecycle actions. Permanent deletion requires confirmation. Legacy resource APIs and MCP tools stay links-only.

The compact editor has safe Markdown, deterministic title fallback, optional organisation controls and account-scoped session drafts. Explicit discard removes a draft. Storage failure leaves saving available with a warning. Conflict review retains typed content and shows the latest revision before retry. Mutations reject an explicitly mismatched account marker. Sign-out/reset/deletion clear drafts and notify other tabs.

PDF originals are limited to 20 MiB, with user-approved 500 MiB per account and 5 GiB globally, including pending uploads/deletions. Expiring single-use permissions protect direct upload/download. Isolated extraction is limited to 100 pages, 250,000 characters and 30 seconds. Scans/encrypted/malformed inputs fail honestly. Download/extraction verify original size and checksum. Durable workers recover leases and remove all Backblaze object versions after the deletion delay. An independent ordered file journal recovers post-snapshot originals before HTTP startup.

Article/PDF summaries run only on request through free-only OpenRouter with a $0 cap, bounded source text, source references, partial/stale flags and imported provenance. User notes remain separate. Cancellation, quota reservation, ambiguous failures and account deletion have durable handling. See [summary processing](../summary-processing.md) for exact limits and provider privacy terms. A small labelled real-provider set was manually reviewed; this does not guarantee future model output.

JSON v2 preserves all item types, extracted pages, summaries, projects/history and organisation. Data-only restores label missing originals and disable their download. Full ZIP backups stream originals with checksums through transient session-bound permissions and a memory-only download worker. Restore validates every entry, supports interrupted retry and repairs originals without replacing later edits. Bookmark HTML exports titles/URLs only and reports omitted content. Root PWA caches contain public offline assets only.

API/MCP share ownership, scopes, revisions and lifecycle rules. Unused MCP list/search filters accept omission or null; actual foreign IDs remain denied. Real native Codex/OpenCode idea save/retrieve and revocation passed separately from SDK checks. Admin reporting contains counts/operational metadata rather than private content.

Verification recipes live in the [canonical skill](../../.agents/skills/verify-stash/SKILL.md). Evidence includes 108 integration tests, focused desktop/mobile browsers, real B2/OpenRouter checks, an actual disposable dump/restore drill, a 10,001-link migration, native clients and hosted disposable-account acceptance. Results and remaining limitations are in [verification](../verification.md). GitHub CI did not start because of the account's billing restriction. Automated production backups and external alerts remain existing alpha limitations.
