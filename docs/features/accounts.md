# Accounts and profiles

The local redesign starts with a public landing page at `/`, a dedicated signup form at `/signup`, and sign-in at `/signin`. Successful signup/sign-in opens the existing library at `/`; logout and deletion return to the landing page. The live deployment at https://stash.kasitek.co.za still uses the earlier account page until the user approves deployment. Verification and recovery links use this domain; the earlier Vercel hostname redirects to it. Signup and password recovery require at least 8 characters; sign-in accepts the existing account password. Returning users choose Sign in, with Forgot your password available on that form. A captured development email links to explicit email verification or password reset. Users can save resources before verification, but agent keys require verified email when email delivery is enabled. The hosted deployment uses Resend with EMAIL_DISABLED=false: signup sends a verification link, recovery sends a single-use reset link, and agent keys require verified email. The API exposes emailEnabled in the profile and /api/config. EMAIL_DISABLED=true remains available to temporarily disable verification/recovery and permit keys without email verification.

Open profile exposes name, bio, interests, image upload/removal, sign-out, and account deletion with current password plus DELETE confirmation. Resetting a password ends old sessions and revokes agent keys. Profile photos are re-encoded static PNGs; replaced/deleted data is removed from the live profile.

Drive with `tests/browser/journeys.spec.ts` and the account integration tests. Verify the visible updated profile, subsequent login, persisted records, invalid/reused links, rejected image uploads, and failed requests after logout/deletion. The recovery drill verifies deleted-account journal replay after a snapshot restore.
