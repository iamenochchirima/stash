# Public landing page

The redesign is local for review. Anonymous visitors see a public homepage at `/`. Sign up links lead to `/signup`; Sign in leads to `/signin`. Authenticated visitors still open their library at `/`. Verification/reset query links remain compatible.

The hero uses the optimized transparent illustration at `apps/web/public/stash-hero.webp`. Public pages use locally hosted DM Sans and Manrope with included OFL licenses. Copy describes saving during chat/research and retrieving in a later conversation. The centered hero folder is surrounded by small assistant labels using their real marks, with article previews and note cards arriving in a staggered loop. The folder is 44% of the illustration width. Any agent was removed; Lina uses the original icon supplied by the user. These are illustrative examples, not additional verified client integrations. Reduced motion keeps the folder and labels static.

The second section now contains a 13-second illustrated agent conversation. The agent presents an example article; a user request types into the composer, is sent, and receives a confirmation preview. The preview contains thumbnail artwork, a title, example source, summary, note, tags, and collection. A simulated confirmation moves the same card into the reading list and updates the saved count/status.

The demo starts automatically when sufficiently visible and loops after holding the saved result for 1.8 seconds. It pauses out of view or when the browser tab is hidden, then resumes automatically unless manually paused. There is no playback bar, step navigation, or caption below the demo. A small pause/resume control appears only on hover or keyboard focus. Reduced motion presents the saved result without animated playback. The confirmation button can also advance the example manually. This is a static illustrated workflow, labelled Example workflow, with no API requests or live user data. The preview image and reading-time badge are illustrative; this change does not add stored thumbnail or reading-time fields to the real library.
